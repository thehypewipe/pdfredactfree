# RedactFree — Free Online PDF Redaction
Live: https://redactfree.com | Contact: hello@redactfree.com

Permanently black out SSNs, bank details, addresses, PHI directly in browser. No uploads, No Adobe, No account.

Features:
- 100% client-side, zero server uploads
- True vector redaction via pdf-lib
- Multi-page, undo/redo, mobile support
- Free forever

Stack: Astro + pdf-lib + WebAssembly
Run: npm install && npm run dev

Roadmap: Claude API for smart auto-detect of sensitive entities.
